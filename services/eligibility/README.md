# Eligibility assistance service

This service explains published requirements, compares them with explicitly provided user context, and returns an explainable match state.

It supports both opportunities and Benefits & Rights.

Suggested output states:

- available_now
- may_qualify
- application_required
- review_required
- not_enough_information

Each output should include:

- reasons
- missing facts
- authoritative source
- last verified date
- caveats
- whether official confirmation is required

This service does **not** determine Indigenous identity, Indian Act registration entitlement, Nation/community citizenship or membership, legal outcomes, admission, hiring, funding, or final benefit eligibility.
