# Eligibility rules

Represents publicly published requirements as explainable, source-backed rules.

Rules must be scoped by the jurisdiction and claimant context they actually apply to. Do not generalize a Status First Nation rule to Inuit or Métis users, and do not generalize a treaty/Nation-specific right beyond its scope.

Each rule should carry:

- authoritative source
- jurisdiction
- claimant class
- effective date when known
- retrieved/verified date
- conditions
- exclusions/caveats
- review state

The package can help produce an explainable match state but cannot decide identity, registration, membership, citizenship, legal outcomes, or final eligibility.
