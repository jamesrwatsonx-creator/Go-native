# Benefits registry

Canonical source registry for Benefits & Rights records.

The registry should contain normalized, source-backed records for federal, provincial, territorial, Nation/treaty/land-claim, school, funder, and verified program-owner benefits.

Required metadata:

- stable record id
- title
- category
- jurisdiction
- claimant class
- province/territory
- Nation/treaty/land-claim scope when relevant
- reserve/on-reserve context when relevant
- eligibility summary
- official application/source URL
- publisher
- application required yes/no
- effective date when known
- retrieved date
- last verified date
- trust tier
- review state
- caveats
- refresh cadence

No entry becomes authoritative because an AI extracted it. Tier 1 official sources are preferred for tax, health, legal, status, treaty/right, and other high-consequence information.
