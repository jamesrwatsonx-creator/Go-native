# Integrations

Integrations are capability adapters, not permission to import data wholesale. Every connector requires: a named owner, legal/privacy review, source provenance, minimal scopes, revocation, rate limits, error handling, and an off switch.

The proposed integration catalog is [docs/integrations/catalog.md](integrations/catalog.md). The architecture-level adoption sequence is in [repository integration plan](repo-integration-plan.md).
