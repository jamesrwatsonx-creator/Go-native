# User flow

## Role-based onboarding

1. Welcome: explain purpose, privacy, and the distinction between assistance and official determination.
2. Choose or create a workspace: Personal, Business, Employer/Recruiter, Nation/Community, Education/Training, Government/Funder, Service Provider, or Procurement Buyer.
3. Select goals, location precision, notification preferences, and optional connections.
4. Complete only the profile fields needed for the chosen goal; defer everything else.
5. See **My Path**: matched opportunities, tasks, documents, messages, milestones, and a visible “why this matters.”

## Core loop

Discover → assess source and fit → save or ask AI to prepare → review required documents/actions → approve communications or submissions → track status → learn from outcome.

## Organization loop

Verify organization → publish opportunities/services → manage applicants or cases → communicate → report outcomes with aggregate, permissioned insights.

## High-risk flow

For ancestry/status/member/citizenship research, Go Native offers source lists, official contact routes, checklists, and document organization. It labels uncertainty and routes to authoritative bodies; it never calculates or announces an identity outcome.
