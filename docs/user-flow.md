# User flow

## Entry

Existing Login visuals are treated as approved. Authentication remains separate from profile/workspace type.

After first authentication, ask:

**What brings you to Go Native?**

- Find opportunities for myself
- Represent an organization
- Both

This selects an onboarding path, not a permanent account type.

## Individual onboarding

1. Location: province/territory; optional Nation/community.
2. Goals: business, education, trades, work, training, grants, scholarships, loans/funding, mentorship, exploration.
3. Interest areas.
4. Current stage.
5. Optional profile depth: education, skills, business stage, preferred modes/locations.
6. Notification preferences.
7. Confirmation: **Your Go Native experience is ready.**

Returning users bypass onboarding and return to personalized Home.

## Individual core loop

Home / Search / Assistant
→ Results
→ Opportunity Detail
→ Why this matches
→ Save / Compare / Apply
→ Track status and documents
→ Deadline reminders
→ Outcome
→ improved future recommendations

## Benefits & Rights flow

Benefits & Rights
→ choose or confirm relevant context
→ federal + province/territory + treaty/Nation-aware results
→ open benefit
→ plain-language summary
→ official source and last-verified date
→ **Get it** / **Do I qualify?** / **I already applied**
→ checklist or case tracking

No screen should imply that “Indigenous” alone creates a universal entitlement.

## Status Navigator flow

Status Navigator
→ choose current state:

- registered + valid card
- registered + expired card
- lost/stolen/damaged card
- registered but no card
- need temporary confirmation
- first secure status card
- unsure / want registration information
- pending application

→ official ISC process
→ checklist + required documents
→ official form/contact link
→ user-controlled status tracking

The app never declares entitlement to registration.

## Organization onboarding

Create Organization Workspace
→ choose organization type
→ collect only relevant organization fields
→ assign owner
→ verification where required
→ provider dashboard
→ create/import opportunity
→ draft/review/publish
→ manage responses and outcomes

## Hybrid account

One Account
→ Personal Profile
→ Organization Workspace A
→ Organization Workspace B

Context switching changes navigation and authorization, not login credentials.

## Provider loop

Verify organization
→ publish opportunity/service
→ receive applications or opted-in matches
→ communicate through permissioned channels
→ update status
→ close/archive
→ aggregate outcome reporting

## High-risk flows

For identity/status/member/citizenship research, legal/justice questions, health benefits, or benefits eligibility, Go Native:

- shows authoritative sources
- labels jurisdiction and uncertainty
- distinguishes general information from official determination
- routes to the appropriate body
- does not invent, infer, or announce a protected legal status or outcome
