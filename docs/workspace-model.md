# Workspace model

A single account may belong to multiple workspaces. A workspace is an authorization and context boundary, not an identity label. Personal data never becomes visible to a business, Nation/community, employer, or funder workspace merely because the same individual participates in both.

| Workspace | Primary intent |
| --- | --- |
| Personal | My Path, discovery, documents, applications, consented assistance |
| Business | services, funding, procurement, team operations |
| Employer/Recruiter | verified opportunities and respectful applicant workflow |
| Nation/Community | community programs, notices, referrals, governed verification |
| Education/Training | programs, learner support, credentials |
| Government/Funder | public programs, funding calls, aggregate outcomes |
| Service Provider | referral, appointments, case collaboration |
| Procurement Buyer | supplier discovery and sourcing workflows |

Roles use relationship-based permissions in OpenFGA and least privilege by default.
